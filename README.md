# 🎮 UPGRADER DEMO

Сучасний демонстраційний вебсайт візуального симулятора апгрейдів предметів у кіберспортивному / неоновому темному стилі.

> ⚠️ **ВАЖЛИВО — DEMO ONLY**:
> Проєкт є виключно візуальною демонстрацією концепції інтерфейсу.
> - **Жодних реальних платежів чи грошей**
> - **Жодних азартних ставок**
> - **Жодного виведення коштів чи депозитів**
> - **Жодних криптовалют**
> - Усі предмети, коефіцієнти та баланс (DP - Demo Points) є вигаданими та зберігаються локально у браузері (`localStorage`).

---

## 🚀 Як відкрити проєкт

Проєкт створено на чистому **HTML5, CSS3 та JavaScript** без додаткових залежностей.

### Варіант 1. Пряме відкриття у браузері
Двічі клікніть або відкрийте файл у будь-якому браузері (Chrome, Edge, Firefox):
`D:\upgrader-demo\index.html`

### Варіант 2. Запуск локального сервера (за бажанням)
У командному рядку або PowerShell у папці `D:\upgrader-demo`:
```powershell
python -m http.server 8080
```
Після чого відкрийте в браузері: `http://localhost:8080`

## ✨ Реалізований функціонал

1. **Темний сучасний інтерфейс**:
   - Неонові акценти (Cyan, Emerald, Purple, Amber).
   - Адаптивна верстка під мобільні пристрої та комп'ютери.
   - Банер-попередження: `DEMO — No real money`.

2. **Центральна Арена Апгрейду**:
   - **Слот «Твій предмет»**: відображає обраний скін із вашого інвентарю (ціна, рідкість, прев'ю).
   - **Слот «Бажаний скін»**: вибір мети для апгрейду.
   - **Радіальне колесо (Canvas Engine)**:
     - Обчислює шанс успіху: `(Вартість вхідного / Вартість цілі) * 95%`.
     - Наочний сектор виграшу на неоновій шкалі.
     - Перемикач напрямку: `▼ Менше (< Under)` або `▲ Більше (> Over)`.
     - Пресети множників: `1.5x`, `2x`, `5x`, `10x`, `50x` (автоматичний підбір цілі).
   - **Велика кнопка «UPGRADE»** зі звуком, візуальним пульсом та блокуванням під час обертання.
   - **Фізична анімація**: плавне сповільнення стрілки (cubic-bezier ease-out) з аудіо-клацаннями.

3. **Синтезатор звуків (Web Audio API)**:
   - Вбудований синтезатор (клацання стрілки, звук запуску, переможна фанфара, звук невдачі). Не потребує завантаження сторонніх mp3-файлів.
   - Кнопка швидкого вимкнення/ввімкнення звуку у верхній панелі.

4. **Демонстраційний Інвентар**:
   - Стартовий набір предметів (7 скінів різних рівнів).
   - Пошук за назвою, фільтрація за рідкістю (Звичайні, Рідкісні, Епічні, Легендарні, Міфічні, Надзвичайні).
   - Сортування за ціною або алфавітом.
   - Кнопка **«+ Отримати Демо-Дроп»** для миттєвого отримання 3 випадкових предметів та бонусних DP.
   - Кнопка скидання інвентарю до початкового стану.

5. **Каталог цілей**:
   - Понад 25 оригінальних векторних кібер-скінів (ножі керамбіт, метелик, снайперські гвинтівки, автомати, пістолети, рукавиці, квантові реліквії).

6. **Історія та Live-стрічка**:
   - Біжучий рядок живих апгрейдів у реальному часі.
   - Вкладка повної історії особистих спроб з фіксацією часу, шансу, випавшого числа та результату.

7. **Профіль гравця**:
   - Кількість спроб, перемог, вінрейт %, рекордний вибитий множник та загальна вартість виграшів.

8. **Збереження стану**:
   - Усі дані синхронізуються через `localStorage`. При перезавантаженні сторінки інвентар і баланс залишаються незмінними.
